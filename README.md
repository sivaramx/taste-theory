# TASTE THEORY

A premium, multi-page restaurant website built using HTML, CSS and JavaScript.

## Overview
TASTE THEORY is a fictional luxury restaurant website concept featuring an elegant dark theme, gold accents and a responsive layout.

## Features
- Home page with a hero section
- Restaurant menu with food cards and prices
- About page introducing the restaurant concept
- Food and restaurant image gallery
- Contact page with a demo contact form
- Reservation page with a demo booking form
- Responsive layouts for desktop and mobile
- Interactive navigation and hover effects

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Project Status
Frontend demonstration project. Contact and reservation forms do not currently connect to a backend or database.
